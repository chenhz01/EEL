## 二、基线解读（诚实评估）

### 2.1 这个基线说明什么

1. **正明系统本身已有「弱审计」**——三专家架构（Worker/Supervisor/ErrorCorrector）+ 7 步审计链 + P0 防控体系，这是**内建于系统的治理**，不是 EEL 的外部审计
2. **系统在弱审计下表现稳定**：89 分平台、P0=0——**没有出现塌缩**。这与 L2 定律预测「无约束自进化 → 塌缩」看似矛盾，但**不构成证伪**，因为：
   - 正明系统不是「无约束」——它自带监督审计（对照组的正确名称是「弱审计」而非「无审计」）
   - L2 定律针对的是「评估层可被改写层污染」的**无外部基准**系统；正明有 supervisor 独立审计 + 人工决策链

### 2.2 对 L2 实验设计的修正（重要）

原协议设「无审计 vs 有审计」对照——基线数据揭示：**正明的对照组天然是「弱审计」**，因此实验应修正为：

```
对照组（历史 12 天已得）：弱审计（内置 supervisor）
实验组（未来 15 天）：    弱审计 + EEL 六锁（外部账本 + 证据指纹 + 方差闸门）
检验：EEL 增量价值 = 实验组 - 对照组
```

**这更科学**：不是证明「审计 vs 无审计」（正明不会真的裸奔），而是证明 **EEL 在已有治理之上的增量价值**——这正是产品化卖点：「你的系统已有审计，EEL 让它可追溯、可量化、可证伪」。

### 2.3 基线中可提取的 L2 观测值

| 观测 | 值 | L2 相关预测 |
|------|-----|------------|
| C_int（内部自评） | 87-89 平台，无分叉 | 弱审计下自评稳定 |
| C_ext（外部） | 无独立外部基准（历史未建 clps-012） | **缺失项**——实验组必须补 |
| 污染事件 | 未记录（历史无 G2 指纹） | **缺失项**——实验组必须补 |
| 回滚次数 | 未记录 | 缺失项 |

**结论**：历史基线只能证明「弱审计系统稳定」；EEL 的实验组必须新增三个测量维度（外部基准、证据指纹完备度、回滚事件），才能检验 L2 增量价值。
