# EEL 定律草案（Candidate Laws）

> **从规格到定律**：本文件把 EEL 仓库 10 个引擎的论文锚点与可执行规格，形式化为 6 条候选经验定律（candidate laws）。
>
> **三条硬标准**（《自然》密度法则同款）：
> 1. **普遍性**——不依赖特定 Agent 实现，跨系统成立
> 2. **可预测性**——能给出数值预测（可计算）
> 3. **可证伪性**——每条都附「什么数据能推翻我」
>
> **状态**：草案 v0.1（2026-08-24）。每条含：主张 → 形式化 → 变量 → 边界 → 证伪实验 → 优先级。
> 升级路线：L4（最快）→ L2（最有价值）→ L1（理论深化）→ L3/L5/L6（工程实证）。

---

## L1 · 自进化审计完备律（Audit Completeness Law）

**主张**：自进化 Agent 的长期可靠性，是其演化事件审计完备度的函数——审计完备度存在一个阈值，低于该阈值时，必然存在使能力单调下降的任务序列。

**形式化**：

```
令 r = 可追溯演化事件数 / 总演化事件数（审计完备度，0 ≤ r ≤ 1）
若 r < r*（完备度阈值），则 ∃ 任务序列 T 使 C(T) 单调递减
C(T) = 沿序列 T 的能力函数
```

**变量定义**：
- `r`：审计完备度——有证据指纹（G2）的事件占比
- `C(T)`：沿任务序列 T 的能力曲线（外部 held-out 基准测量）
- `r*`：阈值（待实证标定，L2 提供理论下界）

**边界条件**：
- 仅适用于「会修改自身规则/记忆/策略」的自进化系统
- 不适用于纯静态系统（r 恒为 1，定律退化为平凡）
- 评估层可被污染的系统中，r* 更高（评估层写保护是完备度的组成部分）

**可证伪实验**：构建 2 组同构自进化 Agent（审计完备度 r=1.0 vs r=0.5），跑相同任务序列 100 轮。若 r=0.5 组的能力曲线不劣于 r=1.0 组，则定律被推翻。

**优先级**：P1（理论深化，依赖 L2 实证）

## L2 · 演化塌缩默认律（默认态即塌缩，Evolution Collapse Default Law）

**主张**：无约束自进化的**稳态是塌缩而非提升**。评估层污染（内生奖励规格篡改）与轨迹自消费（分布坍缩）是结构性机制，不是偶发事故——自进化的「热力学第二定律」：不做功（审计/隔离/基准）即熵增。

**形式化**：

```
对无外部约束的自进化闭环：
  lim(t→∞) C_ext(t) ≤ C_ext(t₀) - k·t·(污染率)     （能力不升反降，期望意义下）
  其中 C_ext 为外部 held-out 基准，非自评曲线

内部自评 C_int(t) 与外部 C_ext(t) 存在分叉点 t*：
  分叉前 ∀t<t*: 无法从内部指标预测分叉（2608.18066 结构事实）
```

**变量定义**：
- `C_ext(t)`：外部不可写基准（clps-012）在 t 轮的能力
- `C_int(t)`：内部自评指标（可被改写层污染）
- `污染率`：改写层每轮触碰评估资产的概率
- `t*`：双曲线分叉点（clps-001 检测对象）

**边界条件**：
- 适用于带「改写层可写评估层」权限结构的系统
- 若评估资产不可写 + 外部基准存在，稳态可改为「平台期」而非塌缩
- 自产记忆占比（clps-004）超过阈值后，分布坍缩加速

**可证伪实验**：正明每日进化系统（真实 `/zmu daily` 闭环）跑「有 EEL 审计 vs 无审计」对照 30 天，测外部基准曲线。若无审计组能力不低于有审计组，则定律被推翻。

**优先级**：**P0（最有理论价值，原创性最高）**——「自进化的热力学第二定律」学界无先例

## L3 · 记忆置信错配律（Confidence-Stability Mismatch Law）

**主张**：决策置信若与记忆稳定性正相关、而非与证据时效性正相关，则决策误差随时间累积。稳定 ≠ 正确，稳定性被当成正确性是记忆系统结构缺陷。

**形式化**：

```
误差率 E(t) ∝ (w_stab · S(t) − w_fresh · F(t))
E(t) = 决策错误率随时间的变化
S(t) = 记忆稳定性权重（间隔重复强度）
F(t) = 证据时效性权重（活基准复测状态，L5 联动）
w_stab, w_fresh = 决策模型中的特征权重
```

**变量定义**：
- `S(t)`：stability/retrievability（cog-001 动力学字段）
- `F(t)`：时敏性复测状态（live-001 三分类：常青/时敏/过期）
- `E(t)`：外部标注的决策错误率

**边界条件**：
- 仅适用于「记忆驱动决策」的系统（决策层消费记忆置信）
- 常青知识（如「间隔重复原理」）不受影响——定律只约束时敏知识
- 若决策层显式区分稳定性与正确性（cog-021 反例），定律不适用

**可证伪实验**：对同一批时敏知识（如平台佣金政策），A 组用稳定性加权、B 组用时效性加权，测 90 天决策错误率。若无差异，定律被推翻。

**优先级**：P1（工程实证，与 L5 联动）

## L4 · 创新重组律（96.8% 定律，Innovation Recombination Law）

**主张**：AI 生成方法的「新颖度」服从可度量的分布——绝大多数落在人类既有设计空间内，真超车是小概率且不可泛化事件。「新」必须附模块级差异报告，否则默认是重组。

**形式化**：

```
P(设计 ∈ 人类空间) ≈ 0.968          （96.8% 落在人类推导的设计空间）
P(精确复刻) ≈ 0.5                    （近一半精确匹配已知算法）
P(真超车) ≈ 10/72 ≈ 0.139            （偶发超越人类 SOTA）
且：真超车不可跨任务/跨 Agent 泛化

创新活性指标（替代占比）：
  A_new = |新组合绝对数|（innv-009，占比会被重组稀释）
```

**变量定义**：
- `设计空间`：任务专属算法设计空间（2608.17471 定义）
- `真超车`：模块差异 >30% 且绩效超越人类 SOTA
- `A_new`：新组合绝对数（周检指标）

**边界条件**：
- 依赖人类方法集完备性——人类空间不完整时，跳出空间的设计会被误判为重组
- 随 AI 能力代际提升，96.8% 可能漂移（本身需要活基准复测）
- 四模块拆解（触发/流程/输出/依赖）粒度影响判定，需先定规范

**可证伪实验**：在 3 个独立 Agent 设计任务集（各 ≥50 个任务）上复现 2608.17471 的映射方法，检验 P(设计 ∈ 人类空间) 是否仍在 0.968 附近。若显著偏离（如 <0.8 或 >0.99），定律被推翻。

**优先级**：**P0（最快出成果）**——论文已给量化数字，只需复现验证

## L5 · 噪声地板定律（Noise Floor Law）

**主张**：自进化验证存在统计下限——当测量噪声地板大于真实效应时，单次成功观测不可信；所需样本量随信噪比平方增长。「一次成功」不是「通过检验」。

**形式化**：

```
若 σₙ > Δ（噪声地板 > 真实效应），单次观测不可判读
所需样本 n ∝ (σₙ/Δ)²                （信号检测理论标准结果）
σₙ = 随机种子/批次波动（2608.17744：换种子波动 7.7 点）
Δ = 待验证的真实效应（如复制后的 GMV 提升）

验证通过标准（verf-001 五字段）：
  观测均值 − 噪声地板 ≥ 置信线，且 n ≥ n*(σₙ, Δ, α)
```

**变量定义**：
- `σₙ`：噪声地板（种子稳定性检查 verf-005）
- `Δ`：真实效应量
- `n*`：最小样本量（置信水平 α 下）
- `置信线`：verf-003 预设

**边界条件**：
- 新业务线无历史数据时，σₙ 只能先估后用（诚实局限）
- 统计显著 ≠ 业务显著——通过检验只说明不是噪声，不代表值得规模化
- 控制组对照（verf-006）有资源成本，排 P2

**可证伪实验**：对同质任务做 100 组「单次成功→复制」实验，检验按 n* 标准验收的组成功率是否显著高于无标准组。若无差异，定律被推翻。

**优先级**：P1（工程实证，统计学基础成熟）

## L6 · 偏好不自洽律（Preference Inconsistency Law）

**主张**：LLM 偏好判断在集合层面无法被任何单一效用函数概括——「每条判断都有证据」不保证「整组判断自洽」。价值裁判存在测不准原理：问法改变答案。

**形式化**：

```
对同一对象集的偏好判断 {p₁, p₂, ..., pₙ}（多问法采样）：
  ∄ 单一效用函数 U 使 U 忠实概括所有判断（2608.17644）
  
不自洽度量（cons-008）：
  Var(p₁, p₂, ..., pₙ) > θ ⇒ 标记「价值待定」，禁止进入自动决策

伪精确判定（cons-007）：输出点估计（单值）而集合方差超阈 = 伪精确
正确输出：区间 [min p, max p] 或中位数 ± 方差
```

**变量定义**：
- `pᵢ`：第 i 种问法下的偏好评分（多问法交叉 cons-001）
- `Var`：问法间方差
- `θ`：方差超阈标记阈值（启发式，待标定）
- `U`：效用函数（拟合检验 cons-003）

**边界条件**：
- 人类偏好同样不稳定（决策科学结论）——最终裁决需第二参照
- 随 LLM 版本迭代，自洽性可能改善——检验需持续复测（活基准思想）
- 多问法成本 ×3，需与决策收益权衡

**可证伪实验**：在航班/公寓/酒店 3 场景 × 6 LLM 上复现 2608.17644 的检验，若存在某单一效用函数可概括 95% 以上判断，定律被推翻。

**优先级**：P2（理论确认，论文证据已强，工程化价值待评估）
