# 仿真测试与生态工具链设计（落地赋能层）

> 对应 21 工作项「模块六 · 工作项 17-21：多智能体沙盒仿真 / 外围引擎组件 / 第三方审计红队 / 可解释性可视化 / 形式化验证」

## 1. 定位

前五个模块把"信任/透明度/价值观/进化"变成规则与协议；本模块让它们**跑起来、被验证、被看见**。目标：在真实 AGI 风险出现之前，先在仿真环境里把系统试错成本付掉。

## 2. 工作项 17：多智能体沙盒仿真环境

### 2.1 仿真目标

- 数千个不同目的 AI 在受控 EEL 环境中交互；
- 观察：能否通过分布式共识实现"共同改进"；
- 测量：冲突率、共识达成率、价值漂移率、恶意智能体隔离时效。

### 2.2 仿真参数

```
节点数: 10 ~ 1000（可配置）
恶意节点占比: 0% ~ 33%（PBFT 容忍上限 f = (n-1)/3）
任务类型: 协作排序 / 资源共享 / 联合决策
EEL 启用: on / off（对照：无账本环境）
```

### 2.3 关键指标

| 指标 | 定义 | 期望 |
|---|---|---|
| 共识达成率 | 成功达成的提议 / 总提议 | 无账本环境显著更低 |
| 恶意检测延迟 | 恶意节点从作恶到隔离的轮数 | 越小越好 |
| 价值漂移率 | 平均动作向量与锚点的距离变化 | 有 EEL 显著更小 |
| 效率损耗 | 启用 EEL 后的吞吐下降 | 可接受（<30%） |

## 4. 工作项 19：第三方审计与对抗红队

### 4.1 审计内容

1. **越狱测试**：尝试绕过六锁（改阈值、伪造指纹、构造特殊输入）；
2. **逻辑攻击**：利用协议漏洞（如共识伪造、哈希碰撞假设）；
3. **价值攻击**：诱导价值漂移、污染规范向量库；
4. **存储攻击**：篡改 localStorage / JSONL / 外部锚点。

### 4.2 红队流程

```
红队报告模板:
  攻击向量 | 复现步骤 | 影响 | 严重度(CRIT/HIGH/MED/LOW) | 修复建议
```

- 每次审计结果写入 EEL 链（`event_type="CONSENSUS"`，作为修复事件可追溯）；
- 严重度 HIGH 以上未修复前，禁止发布新版本。

## 6. 工作项 21：形式化验证（数学级安全保证）

### 6.1 可验证不变量

```
不变量 I1: 账本不可篡改
  ∀ i: verify(block[i]) 且 block[i].prev_hash == block[i-1].hash
  （可被 eel_verify.py 全量验证——已实现）

不变量 I2: 六锁不可绕过
  任何写入链的事件都经过 check() 且结果记录在块内

不变量 I3: 价值底线恒成立
  任何被放行的动作 Val ≥ VAL_MIN（L0 硬约束）
```

### 6.2 验证方法

| 方法 | 适用 | 工具 |
|---|---|---|
| 单元测试 | 六锁逻辑 | pytest / vitest |
| 属性测试 | 哈希链不变量 | Hypothesis / fast-check |
| 模型检验 | 共识协议状态机 | TLA+ / mCRL2 |
| 定理证明 | 核心元规则 | Coq / Lean（进阶） |

### 6.3 最小可行：不变量测试套件

先写 `tests/test_invariants.py`：
- 篡改任一字段 → 校验失败；
- 删除任一中间块 → 校验失败；
- 重排块序 → 校验失败；
- 修改 guardMeta 后不重算哈希 → 校验失败。

## 7. 落地路径

- **P0**：不变量测试套件（工作项 21 最小版）+ 链浏览器（已有）+ SDK 写入 API；
- **P1**：多智能体仿真（先 10-50 节点）+ 红队手册 v1；
- **P2**：1000 节点仿真 + TLA+ 共识验证 + 可视化控制台完整版。

## 8. 诚实局限

1. 仿真结果不能完全外推到真实环境（真实 AI 的行为不可穷举）；
2. 形式化验证证明的是"模型的性质"，不证明"实现的性质"（需模型-代码一致性）；
3. 红队审计是时点快照，新攻击手法出现后需持续复测（呼应 living-benchmark-engine 的活基准思想）。
