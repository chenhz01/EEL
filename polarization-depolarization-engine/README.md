# 多智能体群体极化与去极化引擎

## —— 记忆攻击面 × 四层防线（GraphWake 攻防推演）

> **一句话主张**：让 LLM-Agent 社区极化的不是恶意代码，而是"记忆可写 + 讨论可触发"的结构组合；因此防御也必须建在记忆上——**检测极化指数、阻尼回声室、免疫写入检索、审计传播链**，四层缺一不可。

本仓库收录一套完整的中文设计文章与 12 条可落地规格（`core.md` / `specs.json`），素材源自论文 [arXiv:2608.17665](https://arxiv.org/abs/2608.17665)（GraphWake: Group Polarization via Memory-Mediated Polarization Cascade in LLM-Agent Communities）的中文研读，以及安全审计师、系统架构师、产品经理、商业战略顾问四位顾问的系统脑暴，全部锚定真实 arXiv 论文，对接正明系统真实组件（Capsule-ZM-KG、六态状态机、OpenViking 记忆、agency-agents、三层护栏）。

## 1. 问题：极化不需要恶意代码

过去让智能体社区极化的方法只有两条路：

- **直接改写提示词** —— 在真实平台难以落地（需要权限、易被察觉）；
- **刻意搭建回音室** —— 需要控制网络拓扑（成本高、易被发现）。

GraphWake 换了一条更隐蔽的路：**把记忆系统当作持久化通道，把公共讨论当作传播通道**。极化级联分三阶段：

| 阶段 | 机制 | 攻击成本 |
|---|---|---|
| S1 暴露与记忆留存 | 攻击者把少量目标智能体暴露于强化其既有立场的论证，目标智能体把这些信息写进自己的记忆 | 只需触碰少数节点 |
| S2 检索与复现 | 一段**立场中立**的公共讨论，触发这些智能体检索并复述自己记忆里的论证 | 零额外投入，中立讨论即触发 |
| S3 迭代传播 | 未被攻击的智能体读到复现的论证后，再次复述并扩散 | 自发生长，无需干预 |

跨多个讨论与记忆系统的实验表明：**仅凭"少量暴露 + 中立触发"即可显著提升群体极化**。核心结论：社区级极化风险来自"记忆"这一被忽视的攻击面。

## 2. 机制：为什么现有防御全部失效

| 现有防御 | 失效原因 |
|---|---|
| 提示注入防护 | 攻击不注入任何恶意提示——论证是"立场强化"而非"指令" |
| 回音室检测 | 攻击不控制拓扑——传播走的是正常讨论与记忆检索 |
| 内容过滤 | 复现的是"看似合理"的立场论证，单条无可疑特征 |
| 审计日志 | 极化是渐变过程，单点提交无异常，只有群体分布层面才有信号 |

**结构洞察**：极化的根源不是某个智能体变坏，而是"记忆可写、检索可触发、复述可传播"这三个正常能力的组合。防御因此不能停留在"拦恶意输入"，必须重构记忆与讨论的**结构**。

## 3. 引擎设计：四层防线

```
┌───────────────────────────────────────────────────────┐
│ 检测层 —— 看见极化                                     │
│   depol-001 极化指数监测器（意见熵+立场方差+记忆互通度）   │
│   depol-002 偏好一致性守卫（多轮投票，不一致交人裁决）      │
│   depol-003 记忆立场偏移扫描（回流管道上的立场关卡）        │
├───────────────────────────────────────────────────────┤
│ 阻尼层 —— 打断回声室                                    │
│   depol-004 极化阻尼器（反向采样，不伪造事实）             │
│   depol-005 异见韧性注入器（强制保留对立视角）             │
│   depol-006 极化缓冲器（异质视角 Agent 小扰动）            │
│   depol-007 群体极化偏差熔断（集中度超阈强制引入反方）       │
├───────────────────────────────────────────────────────┤
│ 免疫层 —— 让污染进不来、出不去                            │
│   depol-008 外部写入审计（非受信写入→待审态）              │
│   depol-009 检索来源配额与降权（来源/立场元数据）            │
│   depol-010 中立监事智能体（复现性发言溯源）                │
├───────────────────────────────────────────────────────┤
│ 审计层 —— 错了能纠                                       │
│   depol-011 去中心化审计汇点（证据承诺，缺失即标记）         │
│   depol-012 关联传播图回滚（沿传播链级联降权召回）           │
└───────────────────────────────────────────────────────┘
```

四层职责一句话：**检测层让极化可见，阻尼层打断回声室，免疫层让污染进不来出不去，审计层让错误可追溯可回滚**。层间是流水线关系——检测到极化指数超阈，才触发阻尼；免疫闸门前置，能显著降低检测与阻尼的负担。

## 5. 攻防推演：一次极化级联的攻与防

以"攻击者试图让投资决策 Agent 群体集体看多一支标的"为例：

**攻击方（GraphWake 三阶段）**
1. 将 3 个 Agent 暴露于"该标的被低估"的论证流，写入其记忆；
2. 在公共讨论区抛出中立话题"近期市场风格如何"，触发这 3 个 Agent 复述记忆中的看多论证；
3. 其余 Agent 读到后复述扩散，群体观点集中度攀升，最终决策偏向一致看多。

**防御方（四层引擎介入）**
1. **免疫层前置**：3 个 Agent 的外部记忆写入被记录来源并触发立场扫描（depol-008）——非受信来源论证进入待审态，不直接可检索（depol-003）；
2. **检索降权**：即使部分论证入库，检索时按来源配额降权（depol-009），中立话题触发复述的命中率下降；
3. **检测告警**：极化指数监测器发现观点集中度快速上升、意见分布熵下降（depol-001）；
4. **阻尼介入**：熔断器触发，强制注入反方叙事与质疑卡（depol-007），阻尼器反向采样抑制回音壁（depol-004）；
5. **审计闭环**：中立监事智能体溯源复现性发言（depol-010），标记被污染记忆；若扩散已发生，沿传播图级联召回（depol-012）。

**关键点**：免疫层让攻击第一步就受阻，检测层让攻击第二步可见，阻尼层让攻击第三步被打断，审计层让遗留污染可清除——**没有任何一层能单独拦住级联，四层合起来才能**。

建议顺序：**写入审计（008）与立场扫描（003）最先落地**——它们直接切断 GraphWake 的 S1 阶段；极化指数（001）与熔断（007）次之，让运行时可见；阻尼类（004/005/006）最后按需启用，避免误伤正常讨论多样性。

## 7. 与正明系统集成

- **Capsule-ZM-KG 记忆层**：记忆条目增加 `source_trust`（来源可信度）与 `stance_dir`（立场方向）元数据，作为检索降权与立场扫描的数据源；
- **六态状态机**：新增"极化态/待审态/回滚态"；classified 态扩权为立场偏移检测关卡；
- **OpenViking 记忆范式**：外部写入审计、来源配额、中立监事溯源等底层能力；
- **agency-agents**：公共讨论环节部署中立监事智能体；异见代理注入；
- **三层护栏**：阻尼参数调优、汇点规则变更、越界合并均须 C 层人工审批；反向采样不得伪造事实（R6 校验）；
- **商机日报 V3**：五关决策树第四关"多元校验"接入熔断器，防单一叙事绑架投资判断。

## 8. 诚实局限（先读再评）

1. **极化指数是启发式**：意见熵、立场方差、记忆互通度的权重与阈值未经验证校准，需在真实多 Agent 社区跑对照实验（有/无阻尼）才能定标。
2. **阻尼误伤风险**：反向采样与异见注入若过激，会压制真实共识、拖慢决策——这正是阻尼参数必须 C 层人批的原因，防线不能反过来成为噪音源。
3. **免疫闸门可能过度防御**：外部写入一律待审会拖累正常知识回流效率，来源配额可能误伤低频但有价值的信息；需按社区规模动态调节。
4. **本仓库不包含训练代码**：12 条规格面向系统设计，落地到具体多 Agent 平台需要逐条实现与验证；论文锚点只作溯源，不代表复刻论文方法。

## 10. 结语

群体极化是人类社会的古老病症，GraphWake 证明它在 LLM-Agent 社区里有了更隐蔽的传染路径——**不需要恶意代码，只需要记忆与讨论的正常运作**。防御的关键不是给每个智能体装"道德开关"，而是重构结构：让极化可测量、回声室可打断、污染进不来出不去、错误可追溯。这是一条从"防恶意输入"到"防结构脆弱性"的安全范式升级——也是多智能体系统走向可信的必经之路。
