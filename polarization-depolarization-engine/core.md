## 检测层

### depol-001 极化指数监测器（Polarization Index Monitor）

- **优先级**：P0 ｜ **论文锚点**：[2608.17665](https://arxiv.org/abs/2608.17665)
- **问题**：多 Agent 社区极化无量化指标，极化发生过程不可见，无法在早期介入。
- **方案**：监测社区意见分布熵、各智能体立场方差与记忆互通度，组合成极化指数；指数超阈自动告警并进入阻尼流程。
- **来源**：论文CN-w03-01 P2 + 安全审计师第13轮
- **集成**：六态状态机（监测态→极化态）+ 三层护栏运行时看板

### depol-002 偏好一致性守卫（Preference Consistency Guard）

- **优先级**：P1 ｜ **论文锚点**：[2608.17644](https://arxiv.org/abs/2608.17644)
- **问题**：LLM 派生偏好判断不自洽，用其做群体决策会前后矛盾，极化环境下矛盾被掩盖。
- **方案**：对关键偏好做多轮一致性投票，不一致则交人裁决，防止'被极化的偏好'冒充共识。
- **来源**：安全审计师第14轮
- **集成**：三层护栏（C层人工裁决）+ 安全审计Agent

### depol-003 记忆立场偏移扫描（Stance-Drift Scanner）

- **优先级**：P0 ｜ **论文锚点**：[2608.17665](https://arxiv.org/abs/2608.17665)
- **问题**：记忆回流通道（写入→消化→发布→复用）与 GraphWake 攻击路径同构，回流越顺畅攻击面越大。
- **方案**：六态状态机 classified 态扩权为立场偏移检测关卡：每个进入检索池的论证必须过立场扫描，携带来源可信度与立场方向元数据。
- **来源**：对比CN-w17-06
- **集成**：六态状态机（classified 态扩权）+ Capsule-ZM-KG 记忆层

## 阻尼层

### depol-004 极化阻尼器（Polarization Damper）

- **优先级**：P1 ｜ **论文锚点**：[2608.17665](https://arxiv.org/abs/2608.17665)
- **问题**：少数激进策略被放大成回音壁，安全审计看不到极化过程。
- **方案**：监测意见分布熵，极化加剧时注入反向采样抑制回音壁；反向采样不得伪造事实（R6 校验）。
- **来源**：安全审计师第13轮
- **集成**：三层护栏（C层人工审批阻尼参数）+ 防漏洞逻辑校验R6 + 六态状态机（监测→极化→阻尼→回稳→人批→固化）

### depol-005 异见韧性注入器（GraphWake-Dissent）

- **优先级**：P1 ｜ **论文锚点**：[2608.17665](https://arxiv.org/abs/2608.17665)
- **问题**：多 Agent 社区群体极化时少数意见被淹没，系统失去异见韧性。
- **方案**：在社区层注入'必要异见代理'，强制保留对立视角，极化超阈触发立场重构。
- **来源**：系统架构师第9轮
- **集成**：agency-agents + 三层护栏

### depol-006 极化缓冲器（Polarization Buffer）

- **优先级**：P1 ｜ **论文锚点**：[2608.17665](https://arxiv.org/abs/2608.17665)
- **问题**：多 Agent 社群自发极化，像群体偏见放大器，社群被极化拖垮而非从波动中获益。
- **方案**：监测社群极化曲线，超过阈值注入异质视角 Agent，用小扰动维持健康多样性（反脆弱）。
- **来源**：产品经理第13轮
- **集成**：商机日报V3

### depol-007 群体极化偏差熔断（Polarization Circuit-Breaker）

- **优先级**：P0 ｜ **论文锚点**：[2608.17665](https://arxiv.org/abs/2608.17665)
- **问题**：AI 社区内部极化放大单一看多/看空叙事，诱使决策偏离杠铃与遍历性。
- **方案**：社群观点集中度超阈值时强制引入反方叙事，隔离信息茧房；进入五关决策树的'多元校验'关。
- **来源**：商业战略顾问第9轮
- **集成**：商机日报V3 五关决策树（第四关多元校验）+ 杠铃底座守护

## 免疫层

### depol-008 外部写入审计（External Write Audit）

- **优先级**：P0 ｜ **论文锚点**：[2608.17665](https://arxiv.org/abs/2608.17665)
- **问题**：非受信渠道的记忆写入是极化级联的持久化入口，直接可检索即被利用。
- **方案**：任何来自非受信渠道的记忆写入必须记录来源并触发立场偏移扫描，默认进入待审态而非直接可检索。
- **来源**：论文CN-w03-01 P0
- **集成**：OpenViking 记忆（外部写入审计）+ 六态状态机（待审态）

### depol-009 检索来源配额与降权（Retrieval Source Quota）

- **优先级**：P1 ｜ **论文锚点**：[2608.17665](https://arxiv.org/abs/2608.17665)
- **问题**：即便污染内容已入库，若无检索防线，中立讨论仍会触发其复现传播。
- **方案**：记忆条目携带来源可信度与立场方向元数据，检索时按来源配额限制并降权被污染目标记忆；版本化保留但提交通道双闸（写入立场检测+检索降权）。
- **来源**：对比CN-w18-03 + 论文CN集成
- **集成**：OpenViking 记忆（来源/立场元数据）+ Capsule-ZM-KG 检索策略

### depol-010 中立监事智能体（Neutral Monitor Agent）

- **优先级**：P1 ｜ **论文锚点**：[2608.17665](https://arxiv.org/abs/2608.17665)
- **问题**：公共讨论中复现性发言与真实立场难区分，极化以'正常讨论'形态传播。
- **方案**：部署中立监事智能体，对复现性论证做溯源，识别哪些发言来自被污染记忆而非真实立场，隔离并告警。
- **来源**：论文CN-w03-01 P1
- **集成**：agency-agents（公共讨论环节）+ 安全审计Agent

## 审计层

### depol-011 去中心化审计汇点（Decentralized Audit Sink）

- **优先级**：P1 ｜ **论文锚点**：[2608.17282](https://arxiv.org/abs/2608.17282)
- **问题**：去中心化推理无中心审计点，节点共谋或故障难被发现，极化可在子群体内隐蔽生长。
- **方案**：各节点定期向只读审计汇点提交证据承诺，缺失即标记；承诺不可篡改（R6 校验），汇点规则变更须人批。
- **来源**：安全审计师第32轮
- **集成**：三层护栏（C层人批）+ R6 防漏洞逻辑 + 六态状态机（提交→汇聚→缺失→标记→人批→处置）+ 安全审计Agent（汇点账本）

### depol-012 关联传播图回滚（Propagation-Graph Rollback）

- **优先级**：P2 ｜ **论文锚点**：[2608.17665](https://arxiv.org/abs/2608.17665)
- **问题**：单文件回滚救不了已被复述扩散的立场，污染沿传播链持续存在。
- **方案**：回滚预案从单文件升级为'关联传播图'：定位被污染记忆的所有复述节点，沿传播图级联降权与召回。
- **来源**：对比CN-w18-03
- **集成**：Capsule-ZM-KG（传播图边）+ 六态状态机（回滚态）
