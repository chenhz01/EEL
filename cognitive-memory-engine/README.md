# 间隔重复 × 决策耦合记忆引擎

## —— 认知科学家 40 条核心

> **一句话主张**：间隔重复不该只是"记忆巩固工具"，它应该成为**决策系统的置信信号源**。记忆的稳定性（stability）与可提取性（retrievability）一旦参与决策权重计算，"记得牢"与"用得对"就不再是两件事。

本仓库收录一套完整的中文设计文章与 40 条可落地规格（`core-40.md` / `specs.json`），全部由「认知科学家」顾问在 40 轮系统脑暴中产出，每条锚定真实 arXiv 论文，对接正明系统真实组件（Capsule-ZM-KG 记忆层、六态状态机、OpenViking 记忆范式、间隔重复回流）。

## 1. 问题：记得牢 ≠ 用得对

记忆系统与决策系统长期各管一段：

- **记忆系统**（间隔重复、复习调度）只回答"怎么记得住"——在遗忘临界点复习，防止知识衰减；
- **决策系统**（检索、推理、置信评分）只回答"怎么选得对"——调取记忆、评估选项、输出结论。

两者脱节导致一个被反复观察到的失败模式：

> **一条记忆被复习得很牢，却在决策时被错误地、盲目地使用。**

典型场景：模型对一条早已过时（或置信度已崩塌）的记忆"倒背如流"，于是决策时给它与新鲜证据同等的权重；而一条刚写入、尚未验证的新记忆，因为"还不太熟"被系统压低权重——**稳定性被当成了正确性**。

论文 [arXiv:2608.17530](https://arxiv.org/abs/2608.17530)（持续预训练的间隔重复）给出了机制侧的关键证据：复习收益在"即将遗忘点"最大，均匀回放是浪费。这证明**记忆的价值是动态的**——既然记忆强度随时间衰减，决策就不能把记忆当作静态事实。

## 2. 核心机制：SR-Decision Coupling（间隔重复-决策耦合权重）

**cog-021**（P1，锚点 2608.17530）是本引擎的核心，定义如下：

> **把记忆 retrievability 作为决策模型的输入特征：高稳定性记忆在决策中获更高置信权重，低稳定性记忆触发再巩固而非盲用。**

拆成三个可执行规则：

| 规则 | 机制 | 决策侧行为 | 记忆侧行为 |
|---|---|---|---|
| R1 稳定性→置信映射 | stability/retrievability 作为决策特征 | 高稳定性记忆获得更高置信权重 | 无 |
| R2 低稳即降权 | retrievability 跌破阈值 | 该记忆退出决策输入（或降权），结论改为"待核验" | 触发再巩固，进入复习队列前排 |
| R3 决策→调度反馈 | 决策成败回写动力学字段 | 输出决策结论 | 命中即强化、失败即衰减，更新下一轮间隔 |

R3 是传统间隔重复没有的一环，它让闭环成立：**决策在使用记忆的同时，也在给记忆打分**。用得对的记忆被强化，用错的记忆被降权并召回重学——间隔调度不再是日历，而是"使用即提取、提取即评估"的动力学过程。

## 5. 决策耦合闭环：一条记忆的一生

以 cog-021 为主干，串联相关核心，一条记忆从写入到退役的完整生命周期：

1. **写入**：新记忆进入 Capsule-ZM-KG，初始化低 stability、低 retrievability（cog-001 调度器接管）。
2. **巩固**：间隔重复回流按遗忘曲线安排复习；首次正确使用触发加速回报，提前进入强回放窗口（cog-011）。
3. **首次使用**：决策态读取稳定性字段——低稳定性记忆被降权，结论标注"待核验"（cog-021 R2）；若涉及多模态输入，先过不确定感知门（cog-012）。
4. **使用中质疑**：反诘探针自检"前提是什么/反例在哪"（cog-029）；来源不可信则走 R2 可信闸门、降为 System2 待核验补充（cog-033 / cog-013）。
5. **结果回写**：决策成功 → 命中强化，stability 上升；决策失败 → 衰减，回流复习队列（cog-021 R3）。
6. **长期**：高价值分支保活、低价值分支剪枝下沉冷区（cog-023）；跨会话迁移状态快照，避免重复审计（cog-028）。
7. **出问题**：研究环连续失败触发系统熔断，可疑结论隔离（cog-040）；编辑不一致触发全图一致性扫描（cog-037）。

**关键点**：步骤 5 是传统记忆系统缺失的一环——**决策结果是记忆的评分员**。没有它，记忆系统只是在自嗨地复习。

## 7. 与正明系统集成

- **Capsule-ZM-KG 记忆层**：知识胶囊增加 `stability` / `retrievability` / `last_review` 三字段，作为决策特征与复习调度的数据源；

- **OpenViking·ai-memory·memvid 记忆范式**：记忆包序列化、拓扑索引、带宽调度等底层能力；
- **间隔重复回流**：1/3/7/21 天复习梯度，retrievability < 0.6 触发强回放（cog-001 落地参数）。

## 8. 诚实局限（先读再评）

1. **阈值是启发式**：retrievability < 0.6 触发强回放、稳定性→置信的映射函数，均未经验证校准，需在真实记忆库上跑对照实验（均匀回放 vs 间隔重复）才能定标。
2. **耦合权重会放大记忆错误**：若记忆本身是错的，决策给它高权重只会让错误更快固化——这正是 cog-008 审计面板与 cog-013 闸门必须与 cog-021 同批落地的原因，耦合不能单独上线。
3. **40 条规格是"可落地表达"而非论文复现**：每条是论文结论转成的可执行规则，锚点只作溯源，不代表完整复刻了论文方法。
4. **本仓库不包含训练代码**：40 条规格面向系统设计，落地到具体模型需要逐条实现与验证。

## 10. 结语

记忆系统的终点不是"记得住"，而是"敢用、会用、错了能纠"。间隔重复 × 决策耦合的本质，是**让记忆的价值在每一次使用中被重新定价**：用对则升值，用错则降级重学。这是一条从"存储"到"判断"的认知闭环——也是从"会背书的模型"到"会判断的智能体"的分界线。
